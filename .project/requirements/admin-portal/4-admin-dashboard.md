# Epic: Admin Dashboard

## Overview
The Admin Dashboard serves as the central command center for business owners and managers, providing real-time insights, key performance metrics, and quick access to critical business functions.

## User Stories
- As a business owner, I want to see today's bookings at a glance so I can manage daily operations
- As a business owner, I want to see recent activity so I can stay informed about my business
- As a business owner, I want to access key metrics like revenue and bookings so I can track performance

## Features

1. [**Dashboard Overview**](./admin/01-dashboard-overview.md) - Main dashboard layout with key information displayed prominently
2. [**Key Metrics Display**](./admin/02-key-metrics.md) - Real-time business metrics including revenue, bookings, and performance indicators
3. [**Quick Actions Panel**](./admin/03-quick-actions.md) - Fast access to common administrative tasks and frequently used functions
4. [**Recent Activity Feed**](./admin/04-recent-activity.md) - Timeline of recent bookings, changes, and system activities
5. [**Notifications Center**](./admin/05-notifications-center.md) - Alerts and messages for important updates, reminders, and system notifications
