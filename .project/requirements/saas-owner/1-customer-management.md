# Epic: Customer Management

## Overview
Develop a system for platform administrators to view, search, and manage business customers with integrated support tools for account administration and troubleshooting.

## User Stories
- As a platform administrator, I want to view all business customers so I can monitor platform usage
- As a support specialist, I want to search and filter customers so I can quickly find specific accounts
- As an operations manager, I want to manage customer lifecycle so I can handle signups and cancellations
- As a support specialist, I want to add notes to customer accounts so I can track support interactions
- As a platform administrator, I want customer overview dashboards so I can understand account health

## Features
1. [Customer Dashboard](customer-management/1-customer-dashboard.md) - Centralized view of all customers with key metrics and status indicators
2. [Account Creation and Onboarding](customer-management/2-account-creation.md) - Streamlined process for creating new customer accounts and guided onboarding
3. [Customer Search and Filtering](customer-management/3-search-filtering.md) - Basic search capabilities with filters for customer segmentation and analysis
4. [Account Management Tools](customer-management/4-account-management.md) - Tools for managing customer account status, settings, and lifecycle
5. [Customer Support Notes](customer-management/5-support-notes.md) - System for adding and tracking support interactions and account notes
