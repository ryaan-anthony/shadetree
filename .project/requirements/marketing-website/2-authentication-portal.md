# Epic: Authentication & User Management

## Overview
Secure user registration, login, and account management system that enables customers to create accounts, manage their profiles, and access the Shadetree platform. This epic establishes the foundation for user identity management and session handling across the marketing website and customer portal.

## User Stories
- As a new user, I want to create an account easily so that I can access Shadetree's services
- As a returning user, I want to log in securely so that I can manage my business settings
- As a user, I want to reset my password if forgotten so that I can regain access to my account

## Features
1. [**User Registration**](./auth/01-user-registration.md) - Account creation flow with email verification and onboarding
2. [**Login & Session Management**](./auth/02-login-sessions.md) - Secure authentication with session handling and remember me functionality
3. [**Password Management**](./auth/03-password-management.md) - Password reset, change password, and security requirements
4. [**Profile Management**](./auth/04-profile-management.md) - User profile editing, account settings, and preferences
